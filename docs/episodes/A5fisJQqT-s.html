ウクライナ戦争はなぜ終わらないのか？ロシアで強まる強硬論とアメリカの反ロシア勢力

ロシアによるウクライナ侵攻から4年以上が経過しました。多くの人が早期終結を願う中、戦争は一向に終わる気配を見せず、国際情勢はますます混迷を深めています。政治学者のクリス・ノース氏が、この長期化するウクライナ戦争の背景にある複雑な国際関係、ロシアの内情、そしてアメリカとヨーロッパの役割について、鋭い分析を展開しました。

戦争長期化のツケはウクライナ国民に

クリス・ノース氏は、ウクライナ戦争がこれほど長引いていることに驚きを隠しません。彼自身、侵攻開始から4年前の時点で、ゼレンスキー大統領政権が早期に崩壊すると予測していたといいます。しかし、現実は異なり、戦争は今も続いています。ノース氏は、「戦争が長引けば長引くほど、ウクライナという国家、そしてウクライナ国民にとっての損害は大きくなる」と警鐘を鳴らします。甚大な人的・物的被害に加え、経済の疲弊は深刻化の一途をたどっています。

欧米の多額の軍事支援が戦争を継続させる

戦争が継続する大きな理由の一つは、アメリカとヨーロッパ諸国からの継続的な軍事支援です。ドナルド・トランプ前大統領時代はウクライナへの援助に消極的でしたが、バイデン政権に移行してからは、連邦議会が巨額の支援法案を可決。その資金は依然として残っており、ウクライナが戦い続けるための大きな原動力となっています。

また、ヨーロッパ諸国も積極的にウクライナを支援しています。ドイツ、フランス、イギリスといった主要国に加え、ポーランドなどロシアと国境を接する国々は、ウクライナへの軍事・経済援助を継続。これらの支援が、ウクライナが戦線を維持する上で不可欠な要素となっています。

「特別軍事作戦」を続けるロシアのしたたかな戦略

一方、ロシアの戦い方には、欧米とは異なる特徴が見られます。ロシアは、この紛争を「戦争」とは呼ばず、「特別軍事作戦」と称しています。これは単なる言葉遊びではなく、国内体制に大きな影響を与えています。

  • 徴兵制度の不採用: ロシアは国民全体を対象とした大規模な徴兵を行っていません。これは、国内の反戦感情が高まることを防ぎ、国民生活への影響を最小限に抑えるための措置と考えられます。
  • 財政赤字の抑制: 一般的に、大規模な戦争は国家財政に大きな負担をかけ、巨額の赤字を発生させます。しかし、ロシアは経済制裁下にもかかわらず、巨額の財政赤字に陥っていません。これは、プーチン政権が事前に経済対策を講じていたことと、天然資源の輸出先を多角化したことなどが背景にあります。
  • 国内情勢の安定化: プーチン大統領は、戦争の影響を国民生活から可能な限り遠ざけようとしています。徴兵を行わず、インフレ率も15%程度と高水準ながらも、欧米の制裁による経済破綻は免れています。これは、国内の不満を抑制し、政権の安定を図るための戦略と言えるでしょう。

ロシア国内に強まる「強硬論」の圧力

戦争が長期化するにつれて、ロシア国内の世論やエリート層の間では、戦争の進め方について意見の分裂が見られます。一つは、プーチン大統領が掲げる「焦らず、段階的に勝利を目指す」という路線です。しかし、もう一つ、より強硬な「タカ派」勢力が台頭しており、「戦争を加速させ、早期に勝利を収めるべきだ」という主張を強めています。

ノース氏によると、欧米でイメージされる「プーチン大統領が最も過激なタカ派」という見方は誤りであり、実際には彼よりも強硬な勢力がロシア国内に存在するといいます。その代表例が、前大統領のドミートリー・メドベージェフ氏です。彼の発言はしばしば過激な言葉遣いを伴い、タカ派の態度を鮮明にしています。

最近では、プーチン大統領自身も議会演説で「戦闘を加速させる」と示唆し、議員たちから拍手喝采を受けました。これは、彼が国内の強硬論からの圧力を受けていることを示唆しています。ウクライナ第二の都市ハルキウへのロシア軍の接近、主要港湾都市オデッサへのミサイル攻撃などは、戦線が加速している現実を物語っています。

ウクライナによるドローン攻撃がロシアの強硬論を煽る

ウクライナがロシア国内（モスクワ周辺を含む）へのドローン攻撃を頻繁に行っていることも、ロシアの国内世論を硬化させる要因となっています。これらの攻撃が民間施設や民間人を標的とすることで、ロシア国民の間に「反ウクライナ」「反西側」感情が高まり、政府に対し、より断固たる対応と早期勝利を求める圧力が強まっているのです。これはウクライナ側の意図とは異なる「逆効果」を生んでいるとノース氏は分析しています。

苦境に立たされるウクライナとゼレンスキー政権

一方、ウクライナ側は深刻な課題に直面しています。開戦当初から徴兵に大きく依存してきましたが、多くのウクライナ人、特に若年層が徴兵を逃れるためにヨーロッパ諸国へ流出している現状があります。街中で若者が無理やり徴用されるような動画も出回っており、ウクライナ国内では徴兵に対する強い反発が見られます。

このような状況の中、ゼレンスキー大統領は最近、国防大臣と軍の最高司令官を解任しました。これは、戦況がウクライナにとって芳しくないことを示唆する動きと言えるでしょう。もしウクライナが優勢であったなら、最高指導部の交代は必要なかったはずだからです。

戦争の「設計者」と化したアメリカ・欧州の反ロシア勢力

クリス・ノース氏は、この戦争の根源には、アメリカの一部の勢力による明確な計画があったと指摘します。彼の著書『ユダヤ人はなぜ多様性を求めるのか？』でも触れられているように、オバマ政権の国務次官だったビクトリア・ヌーランド氏が、ウクライナをNATOに引き入れ、ロシアに脅威を与えて軍事介入を誘発するという戦略を立案したとされています。その目的は、ロシアの軍事介入を口実に、世界規模の経済制裁を課すことでした。

この計画は、ドナルド・トランプ大統領の就任によって一時中断されました。トランプ大統領は就任初日にヌーランド氏を解任したため、計画の実行が約4～5年遅れることになったのです。この空白期間に、プーチン大統領は経済制裁に耐えうる国内経済体制の構築や、中国との関係強化を進めました。

そして、バイデン政権下でヌーランド氏が国務省に復帰し、計画が再始動。2022年2月のウクライナ侵攻とそれに続く欧米諸国による経済制裁へと繋がりました。しかし、ロシアの周到な準備に加え、中国、インド、インドネシア、パキスタンといった国々が制裁に参加しなかったため、ヌーランド氏の当初の計画は「失敗に終わっていた」とノース氏は断言します。

「ロシア弱体化」を目的とする欧州の強硬派

にもかかわらず、なぜ戦争は続いているのでしょうか。ノース氏によると、計画が失敗した後も、アメリカの故リンゼイ・グラハム上院議員のようなタカ派は、「勝利できなくとも、戦争を続けることでロシアの軍事力を弱体化させられる」という考えを持っていたといいます。同様に、現在のEU指導部も、ロシアに対して強い歴史的な恨みを抱くバルト三国出身者などが要職を占めており、彼らが「反ロシア勢力」として戦争を長引かせる強い動機を持っていると分析されています。

このように、ウクライナ戦争の長期化は、単一の要因ではなく、国際社会の複雑な思惑、各国の国内情勢、そして歴史的な背景が絡み合った結果であることが、クリス・ノース氏の分析から浮き彫りになります。戦争の終結には、これらの多層的な問題を包括的に解決するアプローチが求められていると言えるでしょう。
