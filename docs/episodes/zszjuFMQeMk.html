【松田学のニュース解説】人口減少加速とナフサ不安に苛まれる日本経済の死角と活路は？

2026年6月4日　/　松田政策研究所チャンネル

人口減少とナフサ不安に揺れる日本経済：死角と活路を探る

現在、日本経済は複数の深刻な課題に直面しており、その死角と活路を明確にすることが喫緊の課題となっている。加速する人口減少は労働力不足を深刻化させ、中東情勢の緊迫化はエネルギー供給、特にナフサ価格の高騰を通じて広範な産業と国民生活に影響を与えている。一方で、賃上げや株高といった明るい経済指標も一部に見られるが、その実態は二極化が進む日本経済の歪みを浮き彫りにしている。本稿では、これらの課題を深掘りし、日本が直面する危機とその克服に向けた可能性について考察する。

1. 加速する人口減少と労働力不足の深刻化

日本の人口減少は、もはや地方だけの問題ではない。総務省が発表した2025年国勢調査の速報値によると、日本の総人口は前回調査から約309万人（2.5%）減少し、約1億2300万人となった。これは調査開始以来最大の減少幅であり、人口が増加したのは東京都と沖縄県のみで、埼玉県、千葉県、愛知県といった大都市圏も初めて人口減少に転じた。人口減少の最大の要因は、出生数が出生数を下回る「自然減」の加速である。

この人口減少は、既に日本の産業構造に大きな影響を与えている。特に物流業界では、ドライバーの高齢化が進み、若い働き手が不足しているため、外国人労働者への依存が急速に高まっている。例えば、ヤマトホールディングスは今後5年間でベトナム人ドライバーを最大500人採用する計画であり、他の大手物流企業も10年以内にドライバーの3割を外国人にする目標を掲げている。しかし、外国人労働者の増加は社会の秩序維持に関する新たな課題も生み出し、政府は在留資格の更新・変更手数料や永住許可手数料の大幅な引き上げ、JESTA（日本版ESTA）の導入など、規制強化に乗り出している。

しかし、こうした短期的な対策だけでは根本的な問題は解決しない。国土交通省は自動物流道路やトラックの自動運転技術（レベル4）の実証実験を進めるなど、官民連携で人手不足解消に向けたイノベーションを模索しているが、「いつでも早く届く」というこれまでの当たり前が失われつつあるのが現状だ。

2. 表面的な経済指標と国民生活の実態

最近の経済ニュースでは、賃上げや株高といったポジティブな情報が目立つ。今年の春闘では、大手企業を中心に平均月給が前年を上回る約2万円の引き上げとなり、平均賃上げ率は3年連続で5%を超えた。また、日経平均株価はAIや半導体関連株が牽引し、市場最高値を更新し続けている。これを受けて、個人の確定申告所得の合計額もバブル期に次ぐ規模で増加し、税収も好調である。

しかし、これらの明るい指標の裏には、国民生活の苦境が隠されている。実質賃金は物価上昇に追いついておらず、多くの家計は依然として購買力低下に苦しんでいる。株高の恩恵を受けているのは一部の富裕層やグローバル企業であり、内需に支えられた中小企業や一般市民の生活実感とは乖離がある。これは、グローバリズムと結びついた部門と、国内市場に依存する部門とで経済が二極化している証拠であり、この歪みが解消されない限り、持続的な経済成長は難しいだろう。

また、税収の増加も、物価上昇による「ステルス増税」の側面が強い。インフレによって名目所得が上がると、所得税の累進課税制度によって適用される税率が上がり、実質的な税負担が増加する。政府はこの増収分を財政健全化に充てるのではなく、国民の負担軽減のための減税に回すべきだという意見も多い。

3. 円安の長期化とホルムズ海峡情勢によるエネルギー不安

円安の進行も止まらない。政府・日本銀行は直近1ヶ月間で11兆円を超える巨額の為替介入を行ったが、円相場はわずか1円程度の変動にとどまり、効果は限定的だった。これは、為替介入が根本的な経済構造を改善するものではなく、市場への一時的なメッセージに過ぎないことを示している。日本の経済基盤、特にデジタル赤字やエネルギー赤字といった構造的な問題が解決されない限り、円安基調は変わらないだろう。

さらに、中東情勢の緊迫化は、日本のエネルギー供給に深刻な影を落としている。イランとアメリカの軍事衝突の可能性が高まり、イランがホルムズ海峡の閉鎖を示唆したことで、日本は中東からの原油輸入が約5割、ナフサの輸入が約6割減少する見込みだ。これは、中東へのエネルギー依存度が高い日本にとって、極めて大きな打撃となる。日本は世界でも突出して原油輸入の減少幅が大きく、調達先の多角化が喫緊の課題となっている。

このナフサ不足は、私たちの日常生活にもすでに影響を及ぼしている。ナフサはプラスチック製品の主要原料であり、医療用手袋や食品トレー、様々な包装材などに使われている。スーパーではプラスチック容器の使用を減らすため、惣菜のバラ売りを増やしたり、肉や魚のトレーの色を無色にしてインクを節約したりする動きが出ている。また、小麦価格の高騰も相まって、パンやパスタなどの食品価格も一段と上昇しており、家計を圧迫している。政府は米国などからの代替調達を進めていると説明するが、供給不安が市場での買い占めを招き、「目詰まり現象」が発生しているのが実態だ。

4. 次世代エネルギーとAI：日本の活路

エネルギー自給率の低い日本にとって、この危機は構造転換の好機でもある。小池百合子東京都知事らは、水素やアンモニアといったCO2フリーの次世代エネルギーの活用を政府に提言している。しかし、これらの技術は安全性、コスト、インフラ整備といった課題が多く、本格的な実用化にはまだ数十年を要する。短期的には、安全性を確保した上での原子力発電所の再稼働や、日本が世界最高水準の技術を持つ石炭火力発電のクリーン化を進めることが現実的な選択肢となるだろう。また、食料の安定供給のためには、化学肥料に依存しない有機農業の拡大など、食料自給率向上のための政策も重要だ。

そして、最も注目すべきはAIの領域である。ソフトバンクグループは、フランスで最大14兆円、アメリカのオハイオ州で80兆円もの巨額を投じてAIデータセンターの建設を計画している。これは、AIの計算資源がアメリカに集中するリスクを分散させ、ヨーロッパをアメリカと中国に次ぐ「AI第三極」とする狙いがある。日本もまた、人口減少という課題をAIによって克服し、生産性を飛躍的に向上させる必要がある。しかし、そのためには、単に海外のAI技術を導入するだけでなく、日本独自の価値観に基づいた「日本型AI」を開発し、その普及をリードしていくことが求められる。

結論：日本の「和」を基盤とした国家戦略の必要性

日本が直面する人口減少、エネルギー不安、経済の二極化といった複合的な危機は、経済合理性だけでは解決できない構造的な問題である。為替介入や一時的な景気対策では限界があり、根本的な解決のためには、国家レベルでの長期的な戦略が必要不可欠だ。

その戦略の核となるべきは、日本の「和と調和」の精神に基づいたAI開発、エネルギー自給率の向上、食料自給率の確立である。海外への依存度を減らし、国内の生産性と技術力を高めることで、外的要因に左右されない強靭な経済と社会を築くことができる。特にAI分野においては、アメリカや中国の覇権競争とは一線を画し、倫理的で人間中心の日本型AIを世界に提案することで、新たな国際秩序形成に貢献し、日本のプレゼンスを高めることができるだろう。

しかし、現状では日本の民間資本が海外に流出し、国内への投資が不足している。政府は、これらの重要分野への投資を強力に推進し、国民が安心して暮らせる未来を築くための明確なビジョンを示す必要がある。このピンチをチャンスと捉え、日本の持つ潜在力と価値観を最大限に引き出す国家戦略こそが、日本経済の「死角」を打ち破り、「活路」を切り開く唯一の道筋となるだろう。
